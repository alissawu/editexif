# Camera template provenance

Only standard capture tags from actual files are included. No GPS, identity, MakerNotes, thumbnails or image pixels are distributed. Source photos remain owned by their publishers. Samples were retrieved October 8, 2026. Exposure/ISO are sample values, not measurements of the uploaded scene.

iPhone 13 has no optical telephoto, nor do iPhone 14, iPhone 15 or Pixel 9. Only supported verified lenses appear. Galaxy S24 samples identify SM-S921B, the reviewed Exynos variant. iPhone 13 comparison photos come from the iPhone 14 review and were verified by their actual EXIF model.

To reproduce tags, run python3 scripts/source-templates.py with native ExifTool installed. Source image hashes are checked before use. Only the metadata JSON is distributed.
